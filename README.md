# 테라리움
> 화면 위 작은 테라리움 위젯


## 프로젝트 소개
- **개발 기간**: 2026.10.13~2026.10.27
- **개발 인원**: 1인
- **목적**: 컴퓨터 사용 중 힐링감, 시간대 확인 용도 위젯

## 주요 기능
- **기능 1**: 시간에 따른 배경 색상 자동 변경
- **기능 2**: 테라리움 설정/꾸미기 기능
- **기능 3**: 시간 설정 기능

## 기술 스택
- HTML, CSS, Java

### 사전 요구사항
- java/javafx 설치
- 추후 exe 개발 예정

### 실행 방법
run.bat 실행

